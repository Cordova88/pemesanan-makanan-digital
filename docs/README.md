# Panduan RasaKita

Dokumentasi untuk branch **ahmad**. Pilih panduan sesuai tujuan:

| Tujuan | Baca |
|---|---|
| Baru clone dan ingin menjalankan web | [README proyek](../README.md) — lima langkah instalasi, foto, dan pembaruan. |
| Memahami atau mengubah kode | [Pengembangan](PANDUAN_PENGEMBANGAN.md) — struktur, model, API, OOP, dan hybrid AI. |
| Mencoba sebagai pelanggan/staf/kasir | [Penggunaan](PANDUAN_PENGGUNAAN.md) — akun, langkah operasional, dan simulasi. |
| Memakai setiap form CMS | [CMS/Admin](PANDUAN_CMS_ADMIN.md). |
| Menguji lokal atau Gemini opsional | [Pengujian lokal](PANDUAN_TESTING_LOKAL.md). |
| Memeriksa persiapan hosting | [Verifikasi hosting](PANDUAN_VERIFIKASI_HOSTING.md). |
| Memahami profil dan data lokal | [Acuan baseline](V1_BASELINE.md). |

Diagram Mermaid tampil pada dokumen GitHub. Tautan SVG di bawah diagram dapat
dipakai jika editor Markdown tidak merender Mermaid. Diagram memuat bagian inti
agar tetap terbaca, bukan seluruh detail model.

Riwayat audit/fase disimpan terpisah pada workspace penulis di
`UTS/output/pengembangan/`. Folder itu tidak ikut clone dan tidak diperlukan
untuk menjalankan web. Panduan instalasi utama adalah README, bukan perintah
penyiapan lama di catatan fase.
